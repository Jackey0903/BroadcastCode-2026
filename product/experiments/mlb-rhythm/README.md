# 四拍叙事试验：先火箭练习，再做独行侠

分支：`experiment/mlb-narrative-rhythm`。基于 `05de168`，新增独立试验入口，不替换原产品入口或正式 Agent 协议。

目标是借鉴 MLB 情境数据的叙事节奏：**完整看进攻 → 回看出手前动作 → 揭示对应官方 xFG → 恢复动态画面解释结果与机会**。不复用棒球模型，不新增预测数字。

## 素材和官方关联

数据直接读取 `product/data/stories.json`，启动和渲染核对原片 SHA-256、事件 verified 状态与官方指标一致性。

|样片|角色|事件|官方 xFG|原片时长|
|---|---|---|---|---|
|阿门 / 火箭进攻|经验试验|game 0022500491 / event 396|44.5%|22.894875 秒|
|弗拉格 / 独行侠进攻|最终方向|game 0022500701 / event 666|51.0%|21.548118 秒|

官方事件、来源 URL、身份和数值沿用现有核对记录。原片来自主办方公开训练视频；媒体不进入 Git。这里的“最终方向”指用户选定的独行侠案例，不表示正式考试素材或已提交作品。

## 火箭第一版复盘与改进

实际生成火箭第一版后，检查了完整文件及回看/指标帧，发现：

1. 一句字幕提前概括整个动作，出现“防守人已起跳”时，画面尚未到对应动作。改为按来源时刻分段：17.5 秒前只提示观察；17.5 秒显示先起跳/仍持球；18.0 秒起显示后续出手。
2. 数据与解释连续使用同一停帧，缺少动作推进。保留第三拍的数据停帧，第四拍恢复原速回看，让指标与动作、结果相连。
3. 独行侠第二拍改为 0.5×、4 秒回看，文字更短，聚焦 16.5 秒画面可见的举臂防守与终结动作；不套用阿门的“先起跳”情节。

上述前两项也回补到火箭练习版。初版 MP4 仅留在本地 `product/build/mlb-rhythm/amen/pilot-v1.mp4`，不作为推荐成片。

## 交互预览

Python 3.11+，无额外 Python 依赖：

```sh
python product/experiments/mlb-rhythm/serve.py --port 4180
```

- 火箭练习：`http://127.0.0.1:4180/?sample=amen`
- 独行侠改进：`http://127.0.0.1:4180/?sample=flagg`

第一、第二拍隐藏指标；第三拍展示官方单次出手数值；第四拍保留指标并恢复原速动作回看。支持步骤切换、重看、原片时钟和官方来源链接。回到第一拍时重新隐藏指标。

预览仅绑定回环地址，仅开放页面、故事快照、已核对原片和指定成片。原片支持 HTTP Range 拖动；没有云端请求、上传接口或新的 Agent 调用。

## 导出完整 MP4

指定本机 FFmpeg 与可合法使用的中文字库路径；字库仅复制到被忽略的 build 目录，不上传 Git。

```sh
python product/experiments/mlb-rhythm/render.py --sample amen --ffmpeg /path/to/ffmpeg --font /path/to/chinese-font.ttf
python product/experiments/mlb-rhythm/render.py --sample flagg --ffmpeg /path/to/ffmpeg --font /path/to/chinese-font.ttf
```

每个样片生成 `product/build/mlb-rhythm/<sample>/enhanced.mp4` 和 `evidence.json`。第一段保留完整原视频内容与原音轨；追加的慢放、数据停帧、原速复盘使用静音，未生成解说。1280×900，字幕位于原画面外。

导出视频约 33 秒。独行侠版在编辑时间约 25.55 秒、火箭版约 27.14 秒才首次揭示 xFG。因为追加回放，输出时钟不等于原片时钟；`evidence.json` 保留各段来源时间、倍率、官方记录和输入/输出哈希。交互视频仍使用原片时钟。

## 已验证与边界

- 两原片哈希与已有官方事件数据一致。
- 两案例浏览器实测：指标延迟揭示、慢放自动停止、第四拍原速动态回看、重置隐藏指标、原片 Range 206、无页面 JS 异常。
- 独行侠 MP4 完整解码成功，含 H.264 视频和 AAC 音轨；实际检查了指标揭示帧和原片防守帧。生成文件需继续按媒体检查核验，不把浏览器交互通过等同于篮球专家认证。
- 关键时刻为编辑窗口，不是自动离手帧识别；字幕不声称骗跳、迫使或战术因果。
- 尚未接入 AgentCore、云端发布、原产品成片渲染器及正式机器评测。交互验证和本地确定性剪辑不冒充新的 AI 推理。

本次试验的可复用结论是“何时揭示与如何回看”，后续可将这些阶段作为 Agent 计划和渲染器的正式时间契约。
