## 2. P0 材质锁定，禁止继续调参

正式 CSS 毛玻璃已经写入 `product/watch/stage/stage.css`，沿用实际代码，不重新拟合苹果材质。

| 项目 | 锁定值 |
|---|---|
| 小型控件背景模糊 | `3px` |
| 底色与不透明度 | `rgba(18,24,34,0.36)` |
| 背景饱和度 | `118%` |
| 白色边缘 | `1px`，白色不透明度 `0.10` |
| 顶部高光 | 白色不透明度 `0.08`，沿用现有 155deg 渐变与 65% 透明终点 |
| 选中底色 | 白色不透明度 `0.15`，保持平整选中态 |
| 投影 | 沿用 `0 8px 24px rgba(0,0,0,.14)` 及当前内高光 |

沿用当前特例，不把 3px 模糊强加到所有面板。
- 右侧战术板与大型内容抽屉保持 `backdrop-filter:none`。
- 三态 opening/closing 期间暂停背景模糊，停稳恢复，维持既有性能保护。
- 静态舞台渐变、文字阴影、圆角及未涉及精简的外观保留。不叠加新的深色蒙版，不调整背景亮度。
- 新增的更多／观赛偏好面板复用这套材质及大小面板规则，不另外设计一套玻璃。

**防止误恢复**
1. `material-lab/index.html` 第一组的初始值仍含 `blur:18` 等探索参数，和用户最终选定参数不同。不要通过“恢复本组”或读取 `presets[0]` 设定正式页面基准。
2. `GlassManager.apply()` 仍写入旧的 `--material-*` 映射值，但当前选定 CSS 使用固定值。不要重新接回旧变量，造成 3px 或 0.36 被悄悄改掉。
3. CSS 材质与旧 liquidGL 光学配置分开。旧预设继续兼容，导入、撤销、恢复或换球队皮肤不能改掉这套 CSS 材质。
4. 调参系统保留。尺寸、字体、布局等仍可独立调整；当前固定材质明确标记为已锁定，不展示会误导用户的无效光学滑杆。不新增调参平台。
5. 对比页保留独立开发用途，不并入正式 Dock、不自动加载、不重新开展六组选型。

默认仍使用 CSS。liquidGL 代码、补丁和原配置保留备用，但不能在首次加载或导入旧预设时自动启用。默认路径不创建 liquidGL Renderer、Lens、输出 Canvas，不做额外的视频氛围采样；视频与战术时间同步继续运行。

## 4. 最终观看交互

### 4.1 默认观看

视频保持主体，两侧默认收起，播放控件沿用按需显隐。进入片段时标题可短暂出现，正常播放时退场，复用现有显隐时长。标题与球员提示分别控制。关闭大标题不应关闭脚底标记。

不常驻大段解说、顶部导航、开发状态、运行记录。已烧录在增强视频中的字幕不能靠删除网页元素去除，本轮不重渲视频。

### 4.2 左侧移入显示 Dock

鼠标移入左边缘后显示，移开后沿用原短延迟收起。鼠标移入内容抽屉、操作菜单或键盘聚焦时保持可用。

| 入口 | 内容 |
|---|---|
| 片段 | 已登记素材，保留当前可用的原片／增强片选择。 |
| 回看 | 一个章节列表。章节内保留正常回放、慢放，相关关注点并入章节。 |
| 数据 | 当前回合或出手的数据、含义、适用范围和来源。 |
| 更多 | 观赛偏好、观看设置、外观与组件、项目与制作、帮助。 |

观看设置保留解释图层开关，接替删除小人按钮后的原功能。外观与组件打开现有中文编辑面板。项目与制作容纳完整来源、运行记录和既有创作台入口，打开记录不创建新任务。

### 4.3 右侧点击显示战术板

- 靠近右侧仅露出轻量开启按钮；悬停不能自动展开。点击或键盘 Enter／空格后展开。
- 一次操作沿用全场形态连续展开到半场的快速动画。默认约 350ms，不添加停顿、二次点击或新过场。
- 展开后移开鼠标不关闭。点击关闭或 Esc 收起。Esc 优先关当前子菜单，再处理战术板。
- 全场／半场在板内选择，手动全场可停留。保留现有约 300ms 视野切换与 220ms 收起配置，中途反向从当前位置继续。
- 主队选项按“球队球场样式”处理，默认跟随真实主队；手动选择只换现有球队皮肤，不改真实主客队、球员身份、比赛数据或攻守方向。
- 关注客队球星不改变主队皮肤。缺 Logo 使用当前文字或中性样式，不另行搜集素材。
- 右板始终独立并排，主视频按实际媒体比例调整，不盖住比赛、不拉伸或裁切画面。

取消旧的右边缘 pointerenter 自动展开，以及 pointermove／pointerleave 触发的右板自动收起。只改右侧行为，不误删左 Dock 的悬停逻辑。

### 4.4 右板与控件减负

右板只保留球队身份、全半场与球队样式选择、球场、必要图例、一句当前动作、来源短标及关闭按钮。

重复的全场／半场大标题删除。底部大卡片改为短说明，小人不恢复。“编辑示意 · 未复核”留一处明显短标，历史点样式及其含义仍保留。来源可点开，不能为了整洁将不确定数据显示为真实追踪。

分辨率放进媒体信息，音量滑条按需展开并保留键盘操作。原始值、事件编号、文件校验值、处理步骤放入详情。

删除内容后只清理明确的多余占位，不趁机重做三态几何。视频比例、比分牌和并排关系优先，不用新卡片填满自然留白。

## 5. 球星关注和四象限

只有一个观赛偏好面板，位于更多。不上四张模式卡、不增加第五个 Dock 图标、不拆四套页面或四个 Agent。

| 设置 | 选项 | 控制什么 |
|---|---|---|
| 关注球员 | 全队／本场一位有可靠身份的球员，支持主客队 | 优先提醒谁。 |
| 篮球熟悉程度 | 入门／熟悉 | 是否解释基础术语。 |
| 观看目的 | 享受比赛／深入分析 | 提醒的克制程度，以及主动展开后的解释深度。 |

后两项组成四象限，前台不必显示“四象限”字样。

|  | 享受比赛 | 深入分析 |
|---|---|---|
| 入门 | 有价值的动作，用一句白话提醒。 | 主动展开后补动作、规则和作用。 |
| 熟悉 | 少打扰，使用简短准确的篮球术语。 | 主动展开后优先看站位、数据和依据。 |

沿用上一份任务的实施默认值“全队／入门／享受比赛”，不强制填写问卷。已有用户选择优先。偏好保存在本机，与样式配置分开，刷新可恢复。换素材时校验关注球员是否还在本场，无效则回全队并轻提示。

### 提醒规则

- 关注覆盖进攻、防守、无球表现，不能只跟当前持球者。
- 只过滤、排序已有且可核验的事件。相同时刻最多一条短提示，不持续刷屏。
- 不自动暂停、放大镜头、切镜头、打开右板或弹大卡片。需要细看由用户回看或点开右板。
- 不剧透未发生的动作和结果，不因喜欢某人夸大贡献。进入全队后恢复已有回合重点。
- 提示避开球、脸、关键动作与原比分牌。复用已接入的轻标记或脚底圈；圈尚未接入就保留接口，不在本轮重做圈动画。
- 用户没选球星，也应正常看比赛，不用强制选择才能播放。

### 身份、位置与内容边界

有可靠身份映射时，左右突出同一人。其他球员点位保留，帮助理解空间关系。临时点击战术点不应偷偷覆盖已保存的关注球员偏好。

未入镜、锚点失效或身份未知时，不凭空贴标；匿名 D/W 不猜人名，脚点不冒充头点。缺球员名单不编造可选名单，只显示已有可核验选择及缺失提示。

缺防守／无球事件，标记待联调。缺不同难度文案时保留已有准确文本，不临时调用新模型，不宣传四种个性化分析已全部完成。增强片的烧录内容不随偏好变化，不重复叠加网页解释。
