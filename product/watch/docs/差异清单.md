# 三态观赛 UI 差异清单

核对日期：2026-10-10，北京时间。基准为开发包三张原图；对照本次最终 v3、1672 × 941 浏览器截图、运行状态和交互记录。

**已交付可运行三态、连续切换、可视化调参和真实 liquidGL 渲染证据；尚不能认定完整视觉验收通过。原生 Mac TV 动态材质对照已取得；精确材质一致性仍有差异，tvOS机顶盒未验收。**

## 一、功能与数据

| 项目 | 当前情况 | 边界 / 待完成 |
|---|---|---|
| 沉浸、全场、半场 | 共用真实 video；一次右边缘触发经过全场进入半场，手动全场可停留 | 交互与录像证据不能代替逐项视觉确认 |
| 视频与右板空间 | 右板并排占位，原片保持比例；最终 v3 形变记录 620 次采样中，视频与右板重叠为 0，同一 video 保持不变，canvas 数始终为 2 | 这些结论只覆盖该次采样，不表示所有设备、所有尺寸均已验收 |
| 左侧入口 | 左 Dock 和内容抽屉按需打开 | 内容抽屉是悬浮层；右战术板始终独立并排，两者用途不同 |
| 真实播放控件 | 播放、进度、音量、速度、全屏使用真实媒体状态；分辨率来自媒体元信息 | 没有额外画质源，不把“1080P”当成清晰度切换菜单 |
| 中文调参 | 组件可选择并实时预览；含独立字族 / 字重，支持恢复、撤销/重做、命名预设、导入导出 | schema 允许反复调整各组件尺寸、颜色、圆角、字体、光学参数和动画；参数可调不表示现有默认值已与原图完全一致 |
| 材质独立分组 | Dock、全场、半场、控制条、内容抽屉、菜单、顶部功能栏、标题胶囊共 8 组独立玻璃 | “批量玻璃参数”明确同时修改 8 组；正常单组件调整不串改兄弟组件 |
| 人物头顶吉祥物 | 正式素材有效头部锚点为 **0**，不会在人物身上凭空贴标；标题、Dock、右板卡片使用原创篮球形象 | 人物头顶跟随尚缺有效头部锚点。独立测试夹具不能作为正式跟踪已完成的证明 |
| 球员点、路线与指标 | 俯视板使用既有匿名 W/D 编号和编辑资料，标出未经复核及过去位置；已有指标保留来源 | 与参考图的人名、球衣号码、路线和演示数字不同；不把脚下坐标当头部锚点，不复制图中的缺失事实 |

## 二、与三张原图的视觉差异

| 对照项 | 当前可见差异 | 原因与后续校准方向 |
|---|---|---|
| R1 沉浸式 | 原片铺满舞台，标题和顶部入口的位置关系已保留；实际章节文案、字量、字号与原图不同，验收截图保留了播放控制条 | 使用真实片段和现有章节，截图时刻也不是原图同一帧；标题层级、间距与控件显隐仍需按基准逐项确认 |
| R2 全场、R3 半场的视频 | 实际原片为 **1920 × 1080、16:9**，并排后视频高度低于生成参考图，画面上下出现更多留白，呈 letterbox 式排布 | 当前保留完整原片与真实比分牌，没有通过拉伸或裁切强行填满参考框。R3 运行记录的实际视频区域约为 1038.4 × 584.1；参考图的框体比例与原片不同 |
| 比分牌 | 原片底部比分牌保留。R2/R3 没有另造原图左上角那套比分牌 | 依照保留原比分牌、不重复计分的要求。真实比赛时钟随原片播放，不替换成参考图中的静态数字 |
| 玻璃、亮边与背景 | 当前 R2/R3 的整体染色更接近深黑灰，原图更偏明亮的蓝灰/紫灰；边缘高光、阴影厚度、折射表现与原图仍有差别 | 已实际运行 liquidGL，并取得同一原片的原生 Mac TV 动态对照。已观察窄亮边、较通透中心；tint、磨砂、折射、倒角的精确一致性仍需校准，不能改变三图布局 |
| 全场球场与底部卡片 | 当前全场球场更高，底部信息比原图简化；没有复制原图中的“10”“5/5”等演示统计 | 球场保持统一比例，并优先呈现已有数据。缺少真实统计时保持缺失，不用演示值补齐视觉 |
| 半场球场与图例 | 当前半场球场占高、文字密度和底部说明区与原图不同；图例使用“浅衣 W / 深衣 D / 示意移动 / 过去位置” | 对应现有数据语义；可以继续独立调整半场比例、字号、内外圆角与地板材质，但不能把未核准身份写成真实人名 |
| 球队标识 | 使用 **HOU / DAL 文字标识**，替代参考图的官方 Logo；中圈也为文字 | 当前未提供可直接使用的官方 Logo 资产；文字占位不是最终徽标还原 |
| 人物标注 | 没有参考图的人体整圈、脚底光圈及完整人物标签群；原创吉祥物只在已有合法位置显示 | 整人描圈按要求取消。正式头部锚点缺失导致头顶标注未实现；不能把“已隐藏错误标注”当成“已完成正确跟随” |
| 控件细节 | 图标、卡片字号、胶囊边缘和球场纹理为现有前端实现，尚未逐像素匹配 | 中文调参可以持续校准，也保留原图一键恢复入口；该入口恢复工程基线，不代表自动消除全部视觉差异 |
