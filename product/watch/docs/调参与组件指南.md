## 观看与切换

初次打开为沉浸式。鼠标移到左边缘，唤出悬浮抽屉；移到右边缘，一次连续展开经过全场进入半场。右板在比赛旁边占据独立空间。

右板上的“全场”“半场”用于手动选择；手动全场可以持续停留。点击关闭或在观看设置中选择“沉浸式”收起。三态共用同一段视频、播放进度、音量和速度。

右上角“•••”或控制条设置按钮 → **样式调试**，打开中文调参窗口。窗口标题可拖动，方便边看边调。

## 选组件并实时调整

先显示要调整的组件，再点“在画面中点选”，点击出现高亮边框的组件；也可以直接使用组件按钮或“正在调整”下拉框。调整全场和半场时，应在对应视图检查效果。

| 参数组 | 主要可调项 | 作用范围 |
|---|---|---|
| 左侧抽屉 | 宽度、圆角、图标大小、间距、文字颜色、玻璃 | 仅左侧抽屉 |
| 全场战术板 | 宽度比例、外壳/球场内框圆角、字号/字体/字重、地板/禁区/线色、线宽、球员点、玻璃 | 全场独立一组，包含 SVG 球员编号 |
| 半场战术板 | 同全场 | 半场独立一组 |
| 播放控制条 | 高度、圆角、时间字号、字体/字重、图标大小、间距、颜色、玻璃 | 控制条时间、分辨率和倍速按钮；弹出菜单单独设置 |
| 内容抽屉 | 宽度、最大高度、基础/标题字号、字体/字重、内边距、圆角、玻璃 | 关键时刻、资料、来源和历史内容 |
| 设置与菜单 | 设置宽度、紧凑菜单宽度、字号/字体/字重、内边距、外壳/选项圆角、玻璃 | 观看设置和倍速菜单 |
| 顶部功能栏 | 字号/字体/字重、圆角、按钮间距、文字颜色、独立玻璃 | 顶部分析入口 |
| 视频标题 | 字号/字体/字重、文字颜色、独立玻璃 | 比赛画面标题与标题胶囊 |
| 球队皮肤 | 跟随比赛、火箭、独行侠、中性 | 只换场地外观，不换比赛资料 |
| 整体空间 / 外观 | 边距、分栏、视频圆角、基础字号 | 页面基础布局 |
| 动画速度 | 打开、全半场切换、收起、离开等待、控件隐藏时间 | 动画与交互 |
| 标注开关 | 视频分析图层、文字标签字号/字体/字重 | 分析显示，不改原视频 |
| 批量玻璃参数 | 折射、磨砂、边缘深度/宽度、染色透明度 | 同时调整左抽屉、内容抽屉、全场、半场、控制条、设置菜单、顶部功能栏、标题胶囊八组 |

滑杆、数字框、颜色和选项会立即预览。每个组件的玻璃参数独立保存；只有明确标注的“批量玻璃参数”和“整体外观”会同时修改多个组件。具体范围由输入框限制，越界值不会写入配置。

“字体”可选 **原图默认、系统字体、苹方、宋体、等宽**；“字重”可选 **原图默认、300、400、500、600、700、800**。原图默认保留各处原有字体与粗细层次；选择具体字重会统一当前组件内的文字粗细。全场与半场分别保存，球场边线文字和 SVG 编号也会应用本组字体，不改变另一形态。控制条字体不会传到倍速弹出菜单。左侧抽屉是纯 SVG 图标，没有虚设字体选项；鼠标悬停的原生提示由浏览器绘制。

字体只使用本机字体白名单，不下载字体；本机缺少某款时，浏览器按该选项的后备字体显示。文字标签仍遵守头锚有效性，调字体不会制造人物标注。选择“原图默认”或“恢复当前组件”可清除字体覆盖。

## 撤销、保存与恢复

- **撤销 / 重做**：恢复本次调参过程；一次滑杆拖动合并为一步。恢复组件、应用预设和导入配置也可撤销。
- **恢复当前组件**：只恢复当前组及其兼容别名；不会清掉其他组件的独立设置。
- **三态布局基准**：展开后点击沉浸式、全场或半场恢复按钮。会恢复全部显示参数并进入该形态，不改变视频时间；撤销恢复的是参数，形态可另行选择。
- **保存当前配置**：将当前值保存到本机浏览器，下次打开自动读取。只预览不会自动保存。
- **命名预设**：填名称后“新建”；选中已有预设可“应用”“更新”“删除”。重命名时，先在名称框填新名称，再点“重命名”。“应用”后若希望下次自动使用，还需保存当前配置。
- **导出 JSON / 导入 JSON**：导出当前配置为版本 3 文件，包含每组字体和字重；旧版本 1/2 和命名预设仍可读取，退役图形参数不会写入新配置，其余设置保留；旧版完整文件若没有任何字体字段，会补为“原图默认”。导入会先整体验证，再替换。非法字段、颜色、类型或越界值会拒绝，保留当前配置。导入后仍需手动保存。命名预设列表不会随单个配置文件导出。

命名预设仅存在当前浏览器，最多 50 个。更换浏览器、地址或端口不会共享；需要转移时使用导出与导入。

## Apple TV 材质对照候选

当前浏览器已保留命名预设“Apple TV 材质对照”。它来自原生 Mac TV.app 播放同一原片后的控件观察，只改播放控件组：染色透明度0.24、磨砂1、折射0.018，其余参数保持基线。它是可选候选，不是精确量化匹配或新默认；演示后已恢复并保存半场原图基准。

在命名预设中选中该名称并“应用”即可比较；恢复时点击半场参考原图，再“保存当前配置”。换浏览器可从交付证据中的 `AppleTV-controls-preset-v2.json` 导入，但单个配置导出不会同时转移命名预设列表。候选保持三张原图布局，不改成 TV.app 的中央大圆按钮。

## 材质、素材与数据边界

调参窗口的“实际 liquidGL 渲染状态”显示当前后端、就绪状态、组件和错误。`css-fallback` 表示降级，不能据此认定液态玻璃视觉验收通过。三张原图始终是布局基准。原生 Mac TV.app 已成功播放同一原片，取得窄亮边、通透中心和控件显隐的动态对照；材质候选预设只用于本机比较，不改源码默认参数，不把布局改成 TV 中央大圆按钮。精确材质与 tvOS机顶盒验收范围见本次记录。

保留原片比分牌。当前未恢复的增强成片只显示缺失状态和历史记录，不用原片冒充增强成片。火箭和独行侠皮肤使用用户选定的 NBA 官方 SVG，顶部徽标与球场中央标志同步切换；中性球场保留文字标识。Logo 是外观素材，火箭红黄版不代表历史比赛球场还原。

俯视板的匿名编号与位置来自已有编辑数据，界面标注“未经复核”；虚线或淡化的过去位置不是实时跟踪。当前没有资料的素材显示空状态，不从参考图补造球员坐标或指标。

人物文字标签需要当前视频内有效、未过期的头部锚点。没有锚点、遮挡、出画或过期时隐藏，脚下/地板坐标不能当头部坐标。当前原片没有可用头部锚点，不会凭空贴到人物上。

## 键盘和播放器

| 操作 | 用途 |
|---|---|
| 空格 | 播放 / 暂停；输入框和按钮保留各自操作 |
| F | 舞台全屏 / 退出全屏 |
| Esc | 先关闭菜单、调参或内容面板，再返回观看；点选模式下取消点选 |
| Tab / Shift+Tab | 移动焦点 |
| 方向键 | 调整已聚焦的进度、音量和参数滑杆 |

进度条控制真实视频时间；拖动期间暂停，松开后恢复原先播放状态。音量、静音、倍速和全屏均作用于同一个视频。分辨率标签来自源视频元信息，不代表另有清晰度切换源。

开发交接接口见 [CONFIG_CONTRACT.md](../dev/CONFIG_CONTRACT.md)。
