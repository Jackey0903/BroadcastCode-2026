# 整段俯视战术示意与球权回放

桌面本地入口：http://127.0.0.1:4173/product/court-lab/。在仓库根目录运行 `python3 product/scripts/serve.py`，弗拉格观看页也有“换个角度，看这一回合”入口。复用已有暖纸、深墨、篮球橙和像素字体，没有新增云端、模型或 GPU 依赖。

## 当前实现

覆盖弗拉格原片完整 **0–21.548118 秒**，原片与 NBA 94 × 50 英尺球场共享唯一视频时钟。支持暂停、半速、拖动、整段回放、半场/全场、队伍筛选、匿名编号聚焦、跟随持球人、1 秒/3 秒/整段轨迹，以及推进、掩护、突破、出手、发球和换边跳转。默认全场，以容纳后场持球推进。

完整名册保留十个匿名编号。已进入画面的对象遇到遮挡/画外时，淡色空心点保留**过去最近位置**，标出距今秒数；不计为当前更新，不画在原片，也不产生新的轨迹。尚未见过的对象不以未来位置倒填。开头约 0.067 秒的人物特写没有球场位置；首个站位锚点约 0.2002 秒。从原片已出现的对象会持续保留显示，直至全片末端。

持球栏、高亮外圈和篮球图标同步显示 D5 控球、出手、命中、W3 收球发球、W2 接球。传球/出手阶段没有持球人。篮球贴随持球人或沿明确标示的战术球路移动；**球路是俯视示意，不是空中球的地面投影或三维追踪**。球权依据实际源帧人工式编辑审查，转换时刻存在抽帧边界误差，见[独立球权核查](ball-possession-audit.md)。白衣28（W4）未接球，已纠正初步猜测。

## 数据边界

`flagg.json` 的 `presentation:"schematic"` 明确表示编辑示意。9–12 秒保留原来的七帧足点与标定；早段从身体/场地线索粗略编辑 court 坐标，后段结合可见足点与粗略地面推断。`inferred` 均 `image:null`，不在原片伪造足点；全部 `reviewed:false`，未经人类专家验收或独立精度评估。

本数据显式设置同镜头可见锚点之间最多 1.25 秒示意插值。遮挡、切镜、过大间隔均断开轨迹；最近位置只是历史快照，不是当前位置推断。普通导入仍保持 0.15 秒默认，旧 schematic 无配置为 0.6 秒，不自动放宽其他记录。

这是一个已编辑样片的解释功能，未实现任意视频自动追踪、自动身份识别、速度/跑动距离测量或战术因果判断。没有更改官方 xFG/事件数据，没有将俯视图加入 Agent 或烧录进增强 MP4。正式计分范围仍以主办方原文为准。

## 文件与复现

- `index.html` / `lab.css` / `lab.js`：桌面界面、唯一视频时钟、阶段解析、球权标记、筛选与本地导入。
- `viewer.js`：校验、时间采样、插值、最近快照、镜头断轨、持球阶段和示意篮球位置。
- `flagg-annotations.json` / `flagg-early-annotations.json` / `generate_schematic.py`：保存源帧真实 PTS、图片哈希、原足点及粗略站位，离线重建默认 JSON。
- `ball-possession-annotations.json`：独立核查的原始九段球权、62 帧引用与边界括定；生成器接入其中的 UI 区间。
- `flow-flagg.json` / `generate.py`：被拒收的光流候选，保留[诊断](../evidence/court-lab-diagnostic-20261009.json)，不能替代默认示意数据。
- `detector/`：官方 YOLO11n 独立三帧验证，未接入产品，见[实测](../evidence/court-detector-20261009.json)。
- [全片最新证据](../evidence/court-full-20261009.json)记录测试和实际浏览器回放；[旧三秒版本](../evidence/court-lab-20261009.json)只作历史记录。

恢复已存档原片后，可重建默认示意：

```sh
python3 product/court-lab/generate_schematic.py
node --test product/tests/test_court_viewer.js product/tests/test_court_endpoint.js product/tests/test_court_dataset.js
```

重建只需 Python 标准库，先核对原片 SHA-256；现有 JSON 可直接播放。原视频不进 Git，从独立媒体存档恢复。ignored 的抽帧目录 `product/build/court-lab/` 可从原片重建，源帧时间/哈希记录保存在源码内。

导入只在浏览器本地读取，不发送后端。仅接受绑定弗拉格源哈希的 `court-lab-v1`，不是官方评测协议。预览服务器只开放指定前端文件与数据；标注、脚本、检测权重不开放。云端发布脚本没有包含本功能。

## 展示方式

点击“回放整段视频”，先看 D5 在全场推进；跳到“掩护”后切进攻半场。打开“跟随持球人”与“整段轨迹”，看突破路线、出手后外圈消失，以及得分后 W3→W2 的球权转换。解释为：“原片看对抗，俯视示意看空间，持球高亮看这一回合如何流动。”
