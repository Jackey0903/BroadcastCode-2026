# RL展示说明：可使用的准确表述

我们在AWS SageMaker GPU上训练了一个3B数据球探，让它通过工具选择NBA官方基础数据、由官方计数计算的高阶效率，以及NBA/AWS深度赛场的引力、影响力和出手质量数据。球探输出有来源的证据，现有视觉与叙事模型负责结合画面解释，程序核验指标和适用范围，最终由后端生成带数据的完整视频。

训练包含监督学习和强化学习：30轮RL采样产生7次真实权重更新。固定小规模评测中，训练后证据任务达到验证集15/16、测试集16/16；本轮RL没有进一步超过监督学习。我们展示的是经过真实GPU训练、能调用官方数据工具并接受程序核验的协作链路，不宣称RL独立提高了视频理解准确率。

## 展示时必须有的实际证据

1. 实际3B端点来源核验，以及这次调用的sourceTrainingJob、adapter、工具轨迹和数据来源。
2. 成片真实使用三层数据，画面标注区分单场赛后统计、派生效率和赛季深度背景。
3. 发布前保留实际失败、程序是否纠错、是否静态兜底；静态兜底不能标成模型输出。
