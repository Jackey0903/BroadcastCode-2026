初赛成绩不带入决赛；先晋级，再用同一底座打磨视觉叙事。技术深度可以来自扎实的数据加工和画面编排，不要求训练新的基础模型。自定义指标需要清晰定义和依据，不冒充官方 xFG、Gravity 或 Leverage。

## 4. 推荐创新组合与得分依据

**主创新：互动式“一拍之前”。** 看原片 → 回到关键时刻 → 选择进攻者或防守者 → 聚焦短回放 → 多看懂一个具体细节。人物选择改变关注内容；不测量眼动、不设置牵强的唯一正确答案、不声称生成新机位。

**支撑一：点解释，让原片作证。** 一句主要解释关联相应片段和数据，使可信度直接成为交互体验。

**支撑二：数据在关键时刻揭示。** 出手时出现一项正确对应的官方数据，帮助解释画面；避免整段常驻密集仪表盘。

|产品/工程增量|最直接服务的评分项|怎样证明价值|
|---|---|---|
|一次关键时刻选择与聚焦回放|初赛 UX 25、决赛视觉 40|评委一次点击看到此前没注意的动作；不同焦点确有不同信息|
|解释绑定片段与原始数据|初赛准确性 30、UX 25；决赛准确性 15、视觉 40|能即时回看核对；减少人物、指标、时刻错配|
|事件匹配与时间映射|初赛机器 35、准确性 30；决赛深度 18|给出实际匹配、冲突处理和时间误差证据|
|不挡球、少跳动的标注布局|初赛 UX 25；决赛深度 18、视觉 40|展示固定标签与加工后标签的真实对照，测有效覆盖和遮挡|
|一套可重跑 Agent 与 CDK 工程|初赛机器 35；决赛架构 18|新输入不改固定答案，生成一致的成片和网页数据|

这张表描述关联，不能把同一功能对应几项就宣称得到了这些分数。创新最终取决于完成度、内容价值与实际效果。

阿门片可作为动作节奏与关注对象的招牌演示；弗拉格片可作为受干扰终结和防守压力补充。两者都需连续视频核准。官方深度数据未拿到前，不填造数值，不把第三节末秒进攻称为比赛绝杀。
