## 复现与凭据

```sh
python3 product/scripts/narrate_moss_continuous.py
python3 product/scripts/narrate_moss_continuous.py --merge-only
```

第一步只出完整音频，供试听；第二步选择最新已完成且同时间轴的干净英文画面，再混音导出。若画面目录出现新版本，只接入其完成清单/hash，不能拿在导出的半成品合并。声画输出均有独立文件名，不覆盖旧MOSS英文片或正式比赛提交片。

需要时执行`--transcribe-only`，仅核对实际音轨文本；不会默认在每次缓存复现重新调用ASR。`.env.moss`仍为本机忽略文件、权限600；源码/前端/回执/备份不含Key。参考声音与合成缓存保存在被忽略的媒体目录，备份音色JSON会去掉签名音频URL。

官方参考：[音色设计](https://platform.mosi.cn/docs/reference/voice-generations/)、[语音合成](https://platform.mosi.cn/docs/reference/speech/)、[实际音频转写](https://platform.mosi.cn/docs/reference/transcriptions/)。
