## 核查结论

主成片链路实际采用AWS原生托管、无服务器、事件驱动与CDK；不是将整个系统搬到自建EC2。主链为CloudFront → Lambda API → SQS → Lambda Worker → AgentCore Runtime／Bedrock → S3；DynamoDB记录任务和预算，CloudWatch Logs记录运行与失败。

不是所有可用AWS服务都要使用，也不能说现有每项都已深入。深度必须对应真实业务行为与运行证据。FFmpeg属于自打包的开源渲染组件，在托管Lambda中执行；它不等于使用MediaConvert。新增服务应解决当前问题，不为凑服务数增加链路。
