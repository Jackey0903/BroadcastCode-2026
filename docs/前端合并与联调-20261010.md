- 测试、Python服务器、npm配置、任意仓库文件与凭据不作为网页资产公开；只有三张被调参界面实际引用的参考PNG明确入白名单，并改成lazy/async加载，不在首屏抢占视频带宽。
- watch 目录由已核验的主产品目录生成，不直接采用前端副本中的旧 CloudFront 地址。视频、分析和运行记录接受受控同源路径，并检查 sample、jobId 与 SHA-256；拒绝跨域媒体、重定向和不匹配的记录。

目录及历史记录加载规则见 [catalog 适配器](../product/watch/adapters/catalog.js)；界面配置仅控制样式，不承载媒体身份、来源坐标或 AWS 凭据，见[参数模块](../product/watch/config/config.js)。
