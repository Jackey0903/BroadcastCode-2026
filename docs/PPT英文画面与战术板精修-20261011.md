本轮按用户要求，把55秒演示片改成英文主文、中文小字辅助，校正三处战术板站位，并替换左上角 Game Mode。新配音由另一进程负责。

当前输出：[GameBuddy-PPT-English-v3.mp4](../product/build/ppt-demo-20261011/english-v3/GameBuddy-PPT-English-v3.mp4)。这是本机生成媒体，不随 Git 分发；v2保留为此前版本。

延续 **55.055秒、3300帧、1920×1080、60000/1001 fps**，所有分段与配音时间点不变。包含原广播及特效音，没有新增 AI 配音。此前中文干净母版、正式提交片和线上页面保留。

## 全英文首尾（v3）

用户不接受开场“争取下一拍”和旧静态结尾，要求首尾使用相同的滑出动效、全英文。

- 开场改为 `DOWN BY 4`（独行侠落后4分），辅以 `5:13 LEFT · 2ND QTR`、`SECOND CHANCE` 和蓝色 `#00 MAX CHRISTIE` 球员条。
- 片尾改为 `DOWN BY 1`，用 `DAL 43 — 44 HOU` 和 `STEP-BACK BANK THREE · OFFICIAL xFG 30%` 说明本球结果；保留英文GameBuddy字标及简短NBA来源。
- 片尾直接复用开场绘制函数：扫描揭示、标题弹入、字幕滑入、蓝条展开；在片尾最后约0.65秒整组向左滑出，斜切条扫过并收黑。
- 开场150帧、片尾330帧及中间所有分段长度不变。英文主文/中文辅助仍用于中段；只有首尾改为全英文。
- 默认正式比赛版本保持原动效；新首尾只由 `--presentation-english` 启用。

## 英文与角标

- 主字幕英文54px、中文25px；战术解释英文46px、中文25px。中文姓名、动作辅助、回放说明同步缩小。
- 数据卡主要标签改为 `NBA OFFICIAL DATA`、`EXPECTED FG%`、`SHOT QUALITY`，保留官方xFG30%、比分与出手距离。
- 战术步骤、攻防图例、右侧阅读提示、片尾数据来源以英文呈现；重复的制作说明精简为一行示意语义。
- 比赛与回放镜头左上角采用黑底、主客队双色侧条的转播角标：`HOU @ DAL` / `DEC 06, 2025 | 7:30 PM CT`。回放另有小型 `REPLAY · 0.5×`，不再出现 Game Mode / 游戏视角。

时间由[本地官方记录](../product/broadcast-fx/formal/data/official.json)的 `gameTimeUTC=2025-12-07T01:30:00Z` 转为 `America/Chicago`，表示达拉斯当地开球时间；主客场和日期与[NBA官方比赛页](https://www.nba.com/game/hou-vs-dal-0022500356)一致。事件273的Q2 4:58仍仅作为该次出手数据，不把它固定为全段比赛钟。

## 三次战术板

旧图用整幅画面坐标线性缩放，未按球场方向建立相对关系，且把身体中心与足点混用。T1远侧球员标记与T3克里斯蒂标记出现越界，T2队形方向也失真。

新版本逐一对照源帧240、480、719，以可见油漆区边线为方向参考，单独审阅攻防相对位置及箭头，使用独立的[展示站位数据](../product/broadcast-fx/data/formal-presentation-court.json)。稳定俯视板状态下，全部标记（含最大脉冲外环）位于边线内，最小净余量约19.3px。

三场标注人数保持9／3／9；T3突出原有三名关键球员。原画面的身体/足点锚点不改，遮挡足点仍保持未知，未补造未入镜球员。俯视位置为经画面审阅的编辑示意，并非自动追踪或测量坐标。
