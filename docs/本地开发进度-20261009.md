## 本轮如何看产品

在仓库根目录运行：

```sh
python3 product/scripts/serve.py
```

打开 http://127.0.0.1:4173/product/。无需 AWS 登录或安装新的前端依赖，预览只监听 `127.0.0.1`。页面显式标明本地模式。

1. 「观看故事」检查两段原片/增强成片，选择关注点、慢放、并排关键帧、官方数据与来源。
2. 「创作工作台」打开「弗拉格 / 阿门 · 历史成片与处理记录」。工具轨迹、模型与耗时来自 10 月 7 日真实生成。
3. 新生成按钮禁用，创建 API 返回 503；不会模拟排队、生成进度或新推理结果。

启动时核对原片及最终 MP4 的 SHA-256。媒体缺失或不一致时提示恢复，不将拒收成片或其他文件替代。Git 克隆只包含源码、说明及证据 JSON；换机器时同时恢复[本地媒体存档](源码保存与恢复.md)。

本轮 HTTP 与媒体核验见[预览记录](../product/evidence/local-preview-20261009.json)，离线测试见[本地测试](../product/evidence/local-tests-20261009.json)。

后续桌面视觉版本详见[旧素材复用与视觉说明](前端视觉更新与旧素材复用-20261009.md)及[111 项测试与浏览器证据](../product/evidence/visual-redesign-20261009.json)。用户已明确以桌面网页展示为目标，后续优先大屏视频、篮球叙事和数据表达。

最新可打开 http://127.0.0.1:4173/product/court-lab/，或从本地弗拉格观看页进入。低精度需求、近似编辑与自动化升级的区别见[俯视调研](俯视图技术调研与实现边界-20261009.md)，当前实际结果与 145 项测试见[俯视验收](../product/evidence/court-lab-20261009.json)。标注、每帧矩阵和标准库重建生成器随 Git 保存，原片仍在媒体存档。检测/光流实验的失败完整保留。
