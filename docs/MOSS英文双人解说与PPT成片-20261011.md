## 解说设计与实际模型

主解说 A 为原创美式男声，负责动作推进、悬念和命中呼喊；分析搭档 B 为另一个原创男声，负责前场篮板、掩护、空间及 xFG。没有使用真人解说员的声音作为参考。

15 段英文稿围绕“封盖后保住球权 → 重新组织 → 撤步打板三分 → 30% 官方 xFG”展开，结果台词从 31.05 秒才进入，晚于可见命中的 30.79 秒。球员为 Max Christie，Dwight Powell 的贡献是进攻篮板；没有补助攻、片外罚球或打四分。

- `moss-voice-generator-1.0`：真实创建两位原创角色音色，保留可复用 voice_id 和参考 WAV。
- `moss-tts-1.5-flash`：当前正式使用，15 段均真实生成英文 WAV，指定 English 和原生期望时长；复用各自角色音色。
- `moss-ttsd-1.0`：已做短试音和第一轮整片候选，但本轮几个短句的转写遗漏了要求的内容。该候选没有选作最终版；[失败记录](../product/evidence/formal-moss-ttsd-initial-20261011.json)保留。这个结果不代表对模型所有场景的通用结论。

风格由原创音色描述、对白措辞、标点、参考音色和时长提示共同形成。JSON 内各段 direction 是剪辑说明，不是向语音接口发送的虚构参数。当前使用官方稳定 model ID，没有把它们声称为固定权重快照。

## 混音与必要核查

对白按成片时间逐段放置，去掉生成音频外侧静音并保持完整句子；调速不超过 1.30 倍，本版实际最大约 1.015 倍。原广播居中的人声先做立体声衰减，再由新对白触发压低，降低多重解说叠声；这不是人声分离或纯观众环境声。

- 真实接口成功、WAV 格式、缓存哈希及每段时长已核对。
- 最终 MP4 全流解码通过，帧数与片长符合冻结时间线。
- 新 MP4 的编码视频流哈希与干净母版一致，混音未改变动画、比分、数据或视频帧。
- `moss-transcribe-diarize-pro` 对新对白进行整段与重点短句转写；球员、篮板、出手、只差一分、thirty percent 与 Game Buddy 收束等 11 个关键表达均出现。
- 自动转写不等于人工音色评审；有少量拼写、词尾转写差异。尚未由用户确认音色，也没有实际打开 PPT 验收播放。本轮没有跑全量工程门禁。

本轮没有重新调用 AgentCore 或 RL；此前正式稿审核、RL 样片验收及已提交作品继续各自保存，不把新音轨记成新的云端 Agent 验收。

## 本地复现与凭据

入口：[narrate_moss.py](../product/scripts/narrate_moss.py)；官方接口适配：[moss_tts.py](../product/agent/moss_tts.py)；稿件：[formal-dialogue-en.json](../product/data/formal-dialogue-en.json)。Python 3.11+ 标准库与本机 FFmpeg/FFprobe 即可；试验性 MLX 环境不参与当前成片制作。

```sh
python3 product/scripts/narrate_moss.py
```

默认采用已实测的 `moss-tts-1.5-flash`；`--sample` 仅试配两处，`--workdir` 可隔离新音色实验。命令会调用真实 MOSS API；已有音色和合成 WAV 按哈希缓存，完整缓存复现不重复付费合成。干净母版受源片、产物哈希及帧数约束，不能随意替换成不同时间轴的视频。

Key 只保存于本机被忽略的 `.env.moss`，权限 600，不进源码、前端、回执或媒体备份。参考声音、分段 WAV、清单及成片另做本地媒体存档；克隆仓库本身不包含这些被忽略的媒体。
